# tauwork-admin · 运营管理平台前端

Vue3 + Element Plus + Vite + Pinia + Vue Router（Soybean-Admin / vue-element-admin 脚手架落地时合并进此结构）

## views 对应运营平台原型 12 页
dashboard 驾驶舱 | crm 客户管理 | booking 预约调度 | deals 商机看板 | product 产品管理(4子Tab)
orders 订单管理 | cases 案件工单 | space 空间运营(4子Tab) | finance 财务 | dist 分销裂变
cms 内容运营 | analytics 数据分析 | settings 系统设置 | login 登录
